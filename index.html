Rainmeter Skin

Spotibar

A sleek, dynamic Rainmeter skin designed to seamlessly integrate Spotify playback controls and album-art-based accent coloring into your desktop interface.

Download Releases Install Guide

Key Features

Packed with smart shortcuts and dynamic media controls built for Windows.

01

Smart Launch & Minimize

Launch Spotify directly from the skin’s Spotify icon. If Spotify closes or isn't running, the skin smoothly minimizes back to the standalone icon.

02

Dynamic Panels & Playback

Hovering over the album cover reveals the Controls Panel and Song Info Panel. Fully supports previous track, play/pause, next track, and repeat functions.

03

Adaptive UI & Gestures

Features an animated progress bar and dynamic track titles matching album art colors. Adjust volume via mouse wheel or trackpad swipe, and mute/unmute with a right-click.

Installation & Setup Guide

Follow these structured instructions to configure Spotibar smoothly on your system.

1. Core Requirements

Install Spotify for Windows and Rainmeter. Download the latest release from the Spotibar Releases page and double-click to install.

Note for Spotify Web Users: Install the WebNowPlaying extension. Always minimize the desktop app rather than closing it completely for best background integration.

2. Recommended Skin Layout Settings

Load the Spotibar skin from your Rainmeter manager and apply these configuration parameters:

  • Position: Set to Stay topmost
  • Draggable: Uncheck
  • Click through: Uncheck

3. Gaming Mode Configuration

Because Spotibar uses Stay topmost to sit neatly on the taskbar, it may overlay fullscreen games. To prevent this:

  • Open Rainmeter and go to Manage > Game Mode.
  • Enable Fullscreen games.
  • Set On start to Unload all skins.
  • Set On stop to Reload saved Spotibar layout.

Achieving the Windows 11 Floating Look

To get the customized Windows 11 taskbar task layout shown in the showcase:

1. Install Windhawk

Download and install Windhawk.

2. Activate Taskbar Styler

Within Windhawk, browse and install the Windows 11 Taskbar Styler module.

3. Apply the Matter Theme

Select the Matter theme to render your taskbar segmentation style properly.
