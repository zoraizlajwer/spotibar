**Spotibar** is a sleek, dynamic Rainmeter skin designed to seamlessly integrate Spotify playback controls and album-art-based accent coloring into your desktop interface.

---

## ✨ Features

* **Smart Launch & Minimize:** Launch Spotify directly from the skin’s Spotify icon. If Spotify closes, the skin smoothly minimizes back to the standalone icon.
* **Dynamic Panels:** Hovering over the album cover reveals the **Controls Panel** and **Song Info Panel** (variant dependent). 
* **Quick Access:** Clicking the album cover or details panel immediately brings the main Spotify window to the foreground.
* **Interactive Playback Controls:** Fully supports **Previous Track**, **Play/Pause**, **Next Track**, and **Repeat**.
* **Gestures & Volume Control:** Adjust volume seamlessly by scrolling your mouse wheel over the skin or using a two-finger swipe gesture on a trackpad. Right-clicking toggles **Mute/Unmute**.
* **Adaptive UI:** Features an animated progress bar that visually tracks playback, with both the progress bar and song title dynamically extracting and adopting an accent color from the current album art.

> **Note for Spotify Web Users:** To use Spotibar with the browser-based version of Spotify, install the [WebNowPlaying browser extension](https://chromewebstore.google.com/detail/webnowplaying/jfakgfcdgpghbbefmdfjkbdlibjgnbli). Ensure the main Spotify desktop application is minimized rather than completely closed for optimal background integration.

## 🛠️ Installation & Setup

1. Install [Spotify for Windows](https://www.spotify.com/download/windows).
2. Install [Rainmeter](https://rainmeter.net).
3. Download the latest `.rmskin` package from the [Spotibar Releases](https://github.com/ZoraizLajwer/spotibar/releases) page and double-click to install.

### Recommended Skin Settings
Load the Spotibar skin from your Rainmeter manager and configure the following layout settings:
* **Position:** `Stay topmost`
* **Draggable:** `Unchecked`
* **Click through:** `Unchecked`

### Gaming Mode Configuration
Because Spotibar uses `Stay topmost` to sit neatly on top of your taskbar, it may occasionally overlay fullscreen games. To prevent this, configure Rainmeter's built-in **Game Mode**:
1. Open Rainmeter.
2. Navigate to **Manage > Game Mode**.
3. Enable **Fullscreen games**.
4. Set **On start** to *Unload all skins*.
5. Set **On stop** to *Reload saved Spotibar layout*.

## 🎨 Taskbar Customization (Optional)
To achieve the customized Windows 11 taskbar aesthetic shown in the preview images:
1. Install [Windhawk](https://windhawk.net/download?version=1.1).
2. Inside Windhawk, install the **Windows 11 Taskbar Styler** mod.
3. Apply the [Matter](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/blob/main/Themes/Matter/README.md) theme style.
